probe_route_template.txt -- 015-IP RP-H, 012-ST JF-A.

The route decision in the shape of the paper's decide_to_react_v1.txt
(three options, the answer after "Answer: Option"), for the generator's
curve beside the typed one on the same constructed states. Three answers
cannot ride a yes/no, so this is the react shape and not decide_to_talk's.
No run ever reads this template: the route is asked on the typed backend
only (JF-1). It lives beside the probe that uses it.
