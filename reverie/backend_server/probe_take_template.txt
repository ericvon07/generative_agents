probe_take_template.txt

The take decision in the shape of the paper's decide_to_talk_v2.txt, for
the generator's curve beside the typed one on the same constructed states.
No run ever reads this template: the take is asked on the typed backend
only (JF-1). It lives beside the probe that uses it.
